# 七巧板探險島

小四 16 關七巧板遊戲。選擇 4A–4C 及 1–25 號後開始。

- 第 1–3 關：彩色與分割線
- 第 4–6 關：分割線
- 第 7–10 關：部分分割線
- 第 11–16 關：單色輪廓

支援拖動、45° 旋轉、翻面、鍵盤操作、幾何過關判定及 Supabase 進度紀錄。同一瀏覽器可續玩。

此儲存庫只有靜態網頁和可公開的 Supabase publishable key，沒有管理金鑰或學生資料。資料存取以每位學生在該瀏覽器的隨機憑證及 RLS 隔離。班別和學號只用作紀錄標籤，並非身分驗證；跨裝置復原未提供。

GitHub Pages：main 分支、根目錄。毋須建置。
